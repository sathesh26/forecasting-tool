User Guide

Step 1 — Import Your Dataset

Upload a CSV or Excel file containing your historical time series. At a minimum, you'll need one column for dates and another for numeric values.

Supported formats: .csv, .xlsx, .xls (max 5 MB)

Alternatively, click Load Sample Data to see how everything works with a built-in 36-month workforce dataset.

Step 2 — Configure the Forecast

Choose which columns represent dates and values. Then set your forecast horizon (how far ahead to predict), seasonal period, and data frequency. Select the models you'd like to evaluate.

Available forecasting engines:

  • Naive Forecast — repeats the last observed value
  • Seasonal Naive — repeats the value from the same period last cycle
  • Moving Average — averages the most recent observations
  • Weighted Moving Average — gives more importance to recent values
  • Simple Exponential Smoothing — decays older observations exponentially
  • Holt's Linear Trend — models an upward or downward trend
  • Holt-Winters Additive — captures trend plus additive seasonal effects
  • Holt-Winters Multiplicative — captures trend plus proportional seasonal effects
  • Linear Regression — fits a straight line through the data
  • Polynomial Regression — fits a curved line for non-linear patterns
  • ARIMA — autoregressive model on differenced data
  • SARIMA — seasonal autoregressive model
  • ETS — auto-selects the best exponential smoothing variant
  • Prophet-style Decomposition — trend plus additive seasonal decomposition
  • Theta Method — blends long-term trend with short-term smoothing

Step 3 — Review the Data

Browse the preview table, review the summary statistics, and glance at the chart to confirm everything looks correct before proceeding.

Step 4 — Run the Models

Click Execute Forecast. Each selected model runs independently — all computation happens in your browser, with no server calls.

Step 5 — Compare Results

Use MAE, RMSE, MAPE, and R² metrics to see which model tracks your historical data most accurately. The comparison table highlights the best performer in each category.

Step 6 — Export Your Forecast

Download the full projection as a CSV file, including fitted values and all forecast horizons, ready for downstream analysis or reporting.

Tip: The recommended model is automatically selected based on the lowest RMSE, giving you a quick starting point for your projections.

About This Tool

This forecasting tool was built to help anyone — from data analysts to operations planners — quickly experiment with different time-series models without needing specialized software or sending data to the cloud.

Upload your data, let it try multiple approaches, and walk away with a projection. Simple as that.
